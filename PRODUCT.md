# Product

## Register

product

## Users

Indonesian social media creators, UMKM (small businesses), and content creators who need quick, natural-sounding captions for Instagram, Twitter/X, and TikTok. They're on mobile or desktop, often in a hurry, posting content regularly. They don't want to think about prompt engineering — they just want a good caption fast.

## Product Purpose

AI Caption generates social media captions that sound human, not machine-written. It uses prompt chaining (AI creates a detailed brief before writing) to produce structured, platform-aware captions from minimal input — even a single word. The tool removes the friction of caption writing so creators can focus on their content.

Success: users get a usable caption in under 10 seconds, copy it, and post. No login, no friction, no learning curve.

## Brand Personality

**Warm editorial minimalism.** Clean, calm, confident. The interface should feel like a well-designed notebook — inviting, not sterile. It speaks Indonesian naturally, not translated-English. It respects the user's time: no unnecessary chrome, no distractions, no upselling in the flow.

Three words: **hangat, bersih, percaya diri** (warm, clean, confident).

## Anti-references

- **SaaS template sites**: gradient hero sections, "trusted by" logo rows, testimonial carousels, pricing cards with checkmarks, "book a demo" CTAs. Everything that screams template.
- **AI tool clichés**: dark themes with neon accents, robot/brain icons, "powered by AI" badges, glowing gradient backgrounds, "magic" copy. The saturated AI aesthetic of 2024-2025.
- **Canva-like overwhelm**: too many options visible at once, toolbars with 50 buttons, cluttered canvases. Simplicity over feature density.
- **Generic chatbot UI**: chat bubble interfaces, typing indicators, "Hi! How can I help you today?" openers. This is a tool, not a conversation.

## Design Principles

1. **Input minimal, output maximal.** The user types one word; AI writes a brief and a full caption. The UI mirrors this: minimal input area, rich output. Don't ask for more than needed.
2. **Editorial restraint.** Every element earns its place. No decorative flourishes, no filler sections. The content IS the design.
3. **Indonesian-first.** All copy, labels, and interactions are in natural Indonesian. Not translated, not formal. Friendly but not childish.
4. **Speed as a feature.** Streaming output, instant copy, no loading spinners where avoidable. The tool should feel fast even when the AI takes a few seconds.
5. **Zero friction.** No login, no onboarding, no tutorial. The user opens the page and generates. Everything is self-explanatory.

## Accessibility & Inclusion

- WCAG 2.1 AA compliance minimum
- Full keyboard navigation for all interactive elements
- Screen reader support with proper ARIA labels
- Reduced motion alternative for all animations
- Color contrast: 4.5:1 minimum for body text, 3:1 for large text
- Touch targets: 44px minimum on mobile
- Language: Indonesian (id), with proper lang attribute
